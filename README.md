# Файлы для итогового задания

В директории `tests` находятся тесты для проверки API, которое должно быть реализовано в веб-сервере.

Директория `web` содержит файлы фронтенда.

# Описание проекта — для чего он создан, что он делает.
Учебный проект планировщика задач на Go. Реализован REST API для управления задачами и подключён готовый веб‑интерфейс. Проект демонстрирует навыки работы с HTTP‑сервером, SQL‑запросами, обработкой параметров и структурой Go‑проекта.

Функционал:

Добавление задачи с заголовком, комментарием, датой и настройкой повтора.
Получение списка задач: пагинация, поиск по подстроке или точной дате.
Пометка задачи как выполненной.
Расчёт следующей даты для повторяющейся задачи.
Хранение данных в SQLite.
Распределение реализации:

API, логика, работа с БД — разработано самостоятельно.
Веб‑интерфейс — предоставленная заготовка (папка web)

# Список выполненных заданий со звёздочкой.
Реализован REST API для управления задачами: добавление, получение списка, пометка как выполненной.
- Добавлена пагинация и поиск в списке задач (по подстроке и по точной дате).
- Реализована логика расчёта следующей даты для повторяющихся задач (`/api/nextdate`).
- Подключён и настроен веб‑интерфейс из папки `web` (раздача статики через `http.FileServer`).
- Работа с SQLite через `modernc.org/sqlite` (без CGO, чистый Go).
- Поддержка переменных окружения: `TODO_PORT`, `TODO_DBFILE`.
- Создан Dockerfile и проверена сборка образа; настроен запуск контейнера с монтированием БД из хоста.

# Инструкция по запуску кода локально
Установленный Go версии 1.23+
VS Code с расширением Go
Открыть папку проекта в терминале
В корне проекта выполнить:
go run .
После запуска открыть: http://localhost:7540

# Запуск контейнера
Docker-образ собран командой 
docker build -t go13-final .

# Инструкция по запуску тестов
Для запуска всех тестов:
go test ./tests/...
Для подробного вывода с логами:
go test ./tests/... -v
